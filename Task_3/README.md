# Play Store Data Analysis - Dual Axis Chart Comparison

## 📋 Project Overview

This project performs a comprehensive analysis of Google Play Store data to create a **dual-axis chart** that compares average installs and revenue for **free vs. paid apps** within the **top 3 app categories**. The chart includes intelligent time-based visibility control, displaying only during the specified time window (1 PM - 2 PM IST).

---

## 🎯 Objective

Create a professional visualization comparing:
- **Primary Axis (Bars)**: Average number of installs for free and paid apps
- **Secondary Axis (Lines)**: Average revenue generated by free and paid apps
- **Scope**: Limited to top 3 categories with strict filtering criteria

---

## 📊 Data Filters Applied

The analysis applies the following filters to ensure data quality and relevance:

| Filter | Criteria | Purpose |
|--------|----------|---------|
| **Minimum Installs** | ≥ 10,000 | Excludes niche/abandoned apps |
| **Minimum Revenue** | ≥ $10,000 | Ensures commercially significant apps |
| **Android Version** | > 4.0 | Modern app compatibility |
| **App Size** | > 15 MB | Substantial applications |
| **Content Rating** | Everyone | Family-friendly content |
| **App Name Length** | ≤ 30 characters | Clean, concise naming |

**Impact**: These filters typically retain 5-15% of the original dataset, focusing on high-quality, commercially viable apps.

## ⏰ Time-Based Visibility Feature

### Scheduling Logic
```
Display Window:  1:00 PM IST - 2:00 PM IST (13:00 - 14:00)
Outside Window:  Chart NOT displayed in dashboard

Timezone:        Asia/Kolkata (IST)
Update Frequency: Real-time (checked on each dashboard load)
```

### Implementation
The `DashboardChart` class provides:
- Automatic time validation
- User-friendly status messages
- Easy integration with dashboard systems

```python
dashboard = DashboardChart()
if dashboard.should_display():
    # Show the chart
    display_chart('dual_axis_chart.png')
else:
    # Show placeholder or hide chart
    show_message("Chart available 1 PM - 2 PM IST")
```

---

## 💡 Key Metrics Explained

### Average Installs
- **Definition**: Mean number of installations per app in category
- **Calculation**: Sum of installs / Number of apps
- **Significance**: Indicates market reach and popularity

### Average Revenue
- **Definition**: Mean total revenue per app in category
- **Calculation**: Sum of (Price × Installs) / Number of apps
- **For Free Apps**: Always $0 (no direct revenue)
- **Significance**: Indicates monetization potential

## 🐛 Troubleshooting

### Issue: "FileNotFoundError: Play_Store_Data.csv"
**Solution**: Ensure CSV file is in the same directory as the notebook

**Solution**: Restart kernel and run all cells in sequence

**Solution**: Run data cleaning in chunks or increase system RAM
